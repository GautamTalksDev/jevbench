# Security policy

## Scope

This policy covers the jevbench repository, its GitHub Actions workflows, and the static `arena/` certificate page.

## Reporting

Report a vulnerability in private. Use GitHub private vulnerability reporting:

https://github.com/GautamTalksDev/jevbench/security/advisories/new

Do not open a public issue for a vulnerability. Do not include exploit details in a pull request.

## Response

The maintainer aims to acknowledge a private report within 7 days.

## Out of scope

TypeSafe's API itself is out of scope. Report those issues to TypeSafe.

A missing result, a disputed label, or a statistical disagreement is a science issue. Use a public issue for those.
